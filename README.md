# CCSDS 123.0-B-2
CCSDS 123.0-B-2 implementation in software. 
The implementation is compliant with the CCSDS 123.0-B-2 (https://public.ccsds.org/Pubs/123x0b2c1.pdf)

The implementation is done in C and provides an API to a lightweight implementation of the core compressor. Only raw data can be compressed with this implementation.
